# 🚀 SmartClipboard | 智能剪贴板管理器

**SmartClipboard** 是一个基于 `PyQt6` 开发的轻量级桌面应用程序。它不仅能记录你复制过的**文本**和**图片**，更强大的功能是它会自动**备份被复制的文件**。即使你删除了原始文件，依然可以从管理器中找回并恢复到剪贴板。

---

## ✨ 核心特性

* **多类型支持**：完美支持文本、图像以及文件/文件夹的监控。
* **文件自动备份**：当你复制文件时，程序会自动将其转存至本地库（`D:/cliplib`），实现全自动归档。
* **持久化存储**：重启电脑或程序后，历史记录依然存在。
* **智能排重**：基于 MD5 哈希算法检测内容，相同内容不会重复记录。
* **置顶显示**：窗口始终置顶，方便在不同软件间切换和快速粘贴。
* **预览功能**：
* 文本：显示摘要。
* 图片：显示缩略图。
* 文件：显示文件图标及名称。



---

## 🛠️ 环境要求

* **Python**: 3.8 或更高版本
* **操作系统**: Windows (代码涉及 `D:/` 盘路径，Linux/macOS 需自行修改路径)

---

## 📦 安装与运行

1. **克隆或下载代码**
2. **安装依赖库**：
```bash
pip install PyQt6

```


3. **运行程序**：

```bash
    python main.py
    ```

---

## 📂 存储结构说明

程序默认在 `D:/cliplib` 路径下建立数据仓库：
*   `/images`: 存储剪贴板捕获的图片（PNG格式）。
*   `/files`: 存储复制的文件副本，按内容哈希值分文件夹管理。
*   `index.json`: 索引数据库，记录所有历史条目的元数据。

---

## 🖥️ 使用指南

1.  **自动监听**：程序启动后会自动进入“监听模式”，你只需照常使用 `Ctrl+C`。
2.  **恢复内容**：在列表中点击任何一项，该条目内容就会重新回到你的系统剪贴板。
3.  **文件恢复**：点击历史中的文件项后，直接在目标文件夹执行“粘贴”，即可还原该文件。
4.  **历史上限**：默认保留最近 50 条记录，超出时会自动清理旧文件，节省磁盘空间。

---

## 💡 技术实现细节

*   **轮询机制**：通过 `QTimer` 每 500ms 检查一次剪贴板状态变化。
*   **哈希校验**：
    *   文本：对 UTF-8 编码进行 MD5。
    *   图像：获取图像二进制位流（`constBits`）计算 MD5。
    *   文件：根据文件路径排序后的字符串计算 MD5。
*   **UI 组件**：使用 `QListWidget` 配合自定义的 `QWidget` 条目，提供富文本/图片的渲染效果。
